Opened before on this device

    Nothing opens? The server must let other devices connect (Admin → Settings → Server & security), and this device must be on the same network. Some devices (Android before version 12, some older routers) don't find .local names: type the address instead. With two servers on the network, openpres.local may open either. On a computer, the desktop manager finds servers by itself.
